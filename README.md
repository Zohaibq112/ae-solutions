# AE Solutions Enterprise Launch

Build an enterprise-grade single-page website for "AE Solutions", an IT advisory and digital transformation company, following the attached specification file. Implement the clean, technical, high-end editorial design language using deep midnight navy (#07111F), dark slate (#101C2C), cool off-white (#F5F7FA), and restrained electric blue accents (#2F80ED). Feature a split hero with an abstract live architecture visual, a positioning statement strip, 5 uniquely designed service cards with miniature interactive diagrams, a connected modern technology ecosystem, a 6-industry asymmetric grid, a 4-step horizontal approach timeline, a full-width interactive multi-tier architecture visualization ("Technology should work as one system"), digital transformation highlights, credibility principles, and a strong dark CTA with footer. Do not invent fake client logos, testimonials, or certifications.
