# AE Solutions enterprise website

## Goal
Build the requested single-page AE Solutions website as a polished, credible technology consultancy experience, using the supplied content and avoiding invented proof points.

## Page structure
- Create a restrained navigation header and split first section with the company positioning on the left and a live architecture visual on the right.
- Add the positioning statement strip directly beneath the opening section.
- Present five distinct service cards, each with a compact interactive technical diagram rather than generic imagery.
- Show the connected technology ecosystem, six-industry asymmetric grid, and four-step horizontal delivery timeline.
- Build the full-width multi-tier architecture centerpiece titled “Technology should work as one system,” with interactive layers and connections.
- Finish with transformation highlights, credibility principles, a decisive dark contact section, and a minimal footer.

## Visual direction
- Use the specified midnight navy, dark slate, cool off-white, white, and restrained electric blue through semantic design tokens.
- Use an editorial sans-serif typography system, precise grids, fine borders, generous whitespace, and restrained motion.
- Keep the page mostly light with focused dark sections; avoid gradients, stock imagery, glass effects, floating decoration, fake metrics, logos, testimonials, awards, or certifications.

## Interaction and responsiveness
- Add meaningful hover/focus responses to service diagrams, ecosystem nodes, timeline steps, and architecture tiers.
- Preserve accessibility with semantic sections, keyboard-operable controls, visible focus states, and reduced-motion support.
- Adapt complex horizontal systems into legible stacked arrangements on smaller screens without hiding content.

## Technical details
- Replace the placeholder home page at `/` and add route-specific metadata.
- Define the design system in the global stylesheet and load the chosen web fonts from the document head.
- Implement the technical visuals with CSS and lightweight React state; no backend or fabricated data is required.
- Validate the rendered page at desktop and mobile sizes, checking layout, interactions, and browser errors.
